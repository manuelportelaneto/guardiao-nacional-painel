# Política de Privacidade Fácil de Ler

> **Nosso Compromisso:** Seus dados servem para melhorar a cidade, não para serem vendidos.

---

## 1. Que dados nós pegamos?
Para o sistema funcionar, precisamos de algumas coisas:

*   **Quem é você:** Nome, e-mail e telefone (para criar sua conta).
*   **Onde você está:** Sua localização (GPS) quando você reporta um problema. Sem isso, a prefeitura não sabe onde fica o buraco.
*   **O que você viu:** As fotos e descrições dos problemas.

## 2. Para que usamos seus dados?
1.  **Validar sua conta:** Para garantir que você é uma pessoa real.
2.  **Mostrar no mapa:** Para colocar o "alfinete" no lugar certo.
3.  **Avisar a Prefeitura:** Enviamos os dados do *problema* para eles resolverem.
4.  **Falar com você:** Para avisar quando o problema for resolvido ou se precisarmos confirmar algo.

## 3. Com quem compartilhamos?
*   **Prefeituras e Órgãos Públicos:** Eles precisam saber sobre os problemas. Compartilhamos o problema, a foto e a localização.
*   **Google (Mapas e Servidores):** Usamos o Google para guardar os dados e desenhar os mapas.
*   **Justiça:** Se um juiz mandar, somos obrigados a compartilhar.

**NUNCA vendemos seus dados para empresas de marketing.**

## 4. O que é Público?
Cuidado com o que escreve nos relatos!
*   A **foto** do problema é pública.
*   A **descrição** do problema é pública.
*   A **localização** do problema é pública.

*Seu telefone e e-mail continuam privados.*

## 5. Como protegemos?
Tudo é guardado com criptografia (uma chave de segurança) nos servidores do Google. Só gente autorizada mexe nisso.

## 6. Seus Direitos
Você é dono dos seus dados. A qualquer momento você pode pedir:
*   Para ver o que temos sobre você.
*   Para corrigir algo errado.
*   Para apagar sua conta.

Para isso, mande um e-mail para: **privacidade@procuradoriacidada.com.br**
