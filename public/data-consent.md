# Consentimento de Uso de Dados

> **Resumo:** Para conectar você à Prefeitura, precisamos que algumas informações suas "viajem" até eles. Aqui explicamos exatamente como isso acontece.

---

## 1. O que é este documento?
Além da Política de Privacidade geral, este termo específico trata do **compartilhamento de dados com o Governo** (Prefeituras, Secretarias e Ministério Público). Como nosso objetivo é resolver problemas públicos, essa comunicação é essencial.

## 2. O que você está autorizando?
Ao usar o Procuradoria Cidadã, você autoriza expressamente que nós enviemos as seguintes informações para os órgãos públicos responsáveis pela sua cidade:

1.  **Relatos de Problemas:** As fotos, textos e categorias que você cadastrar.
2.  **Localização Exata:** As coordenadas GPS de onde o problema foi reportado.
3.  **Identificação Básica:** Em alguns casos, para dar andamento oficial a uma denúncia (como no Ministério Público), pode ser necessário enviar seu **Nome Completo** para oficializar o pedido.
    *   *Nota: Seu telefone e e-mail geralmente não são enviados, a menos que seja um caso de ouvidoria que exija contato direto.*

## 3. Por que isso é necessário?
Sem compartilhar esses dados, a Prefeitura não fica sabendo que o problema existe. Este compartilhamento é a "alma" do aplicativo.

## 4. Dados Abertos
Você compreende e concorda que as informações sobre os problemas urbanos (não seus dados pessoais privados) poderão ser usadas em bases de **Dados Abertos**. Isso significa que pesquisadores, jornalistas e ONGs poderão ver estatísticas como "Quantos buracos existem no bairro X". Isso ajuda a cobrar transparência!

## 5. Posso retirar este consentimento?
Sim. Mas, ao retirar o consentimento para compartilhar dados com a Prefeitura, **você não poderá mais enviar novos relatos**, pois o aplicativo perderia sua função principal. Você ainda poderá usar o app para ver o mapa.
